historical game-specific claims and references; it is not an active target profile

file-grouping evidence, implementation/session logs, old tasks, and scratch work

material was moved into a different harness archive.

notes. Tools may still generate notes or consume project-owned research/approval
paths in a target project; those paths are not bundled harness evidence.

Keep future harness notes about reusable tooling. Target-specific facts,
authorizations, experiments, and reports belong in the corresponding game project.
