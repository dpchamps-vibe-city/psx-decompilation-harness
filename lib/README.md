# Converted SDK inputs

This tree was duplicated from `btn-decompilation/lib/` because the inherited SDK
verification/linking workflow consumes its converted library objects. It is SDK
support material, not recovered game code. The active inherited profile is PSY-Q
4.7; do not treat these objects as a match for another SDK without independent
signature/object/provenance verification.

Original SDK inputs are under `tools/vendor/psyq47/`; version-independent profile
selection and reproducible conversion remain tracked in
`../docs/game-agnosticity.md`. Preserve third-party notices and review SDK
redistribution rights before publication. The package's license does not relicense
these assets.
